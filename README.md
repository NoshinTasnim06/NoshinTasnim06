## 👋 Who I Am

I'm a Computer Science student at St. John's University in New York City, and I like building at the intersection of **software engineering, data systems, and applied AI/ML**. Rather than treating code, databases, and machine learning as separate silos, I'm drawn to programs that handle incoming traffic and requests, move data through clean ETL pipelines, store it reliably in relational databases, and turn it into models or interactive apps people can actually use.

Whether I'm structuring multithreaded application logic, cleaning and transforming raw inputs, designing normalized schemas from scratch, or wiring ML predictions into front-facing tools, I enjoy building both the software structure and the data flow underneath.

## 🚀 What I'm Looking Forward To

My biggest excitement right now is building **multi-language, end-to-end systems** anchored by **robust databases** and **machine learning models**. I want to create software that handles real incoming traffic and data movement—where application code manages requests, scheduling, and user-facing features while data/ETL layers process records, persist them cleanly, and feed ML models or visual dashboards.

As I grow across software, data, and AI/ML, I'm looking forward to:
- **End-to-end architecture:** Connecting incoming traffic/application logic, ETL pipelines, database storage, and ML models or interactive apps into cohesive systems rather than standalone scripts.
- **Multi-language engineering:** Combining languages where each fits best—pairing structured application and systems code with Python and SQL for data processing, querying, and modeling.
- **Applied ML & data reliability:** Getting deeper into ETL workflows, schema design, concurrency, and practical ML/AI pipelines that hold up on larger, real-world datasets.
